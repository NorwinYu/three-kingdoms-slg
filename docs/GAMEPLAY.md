# 烽火三国 · 完整玩法说明

> 这是一个 **AI 生成技术 Demo / 垂直切片**，不是商业游戏。  
> 代码与系统由 DeepSeek Flash 辅助迭代，武将/单位/道具/建筑/地形/背景/视频由 MiniMax H3 生成。  
> 非商业用途，全部生成素材见 [ASSETS.md](ASSETS.md)。

## 1. 游戏目标

你扮演刘备，从涿郡桃园起兵，历经：

1. 桃园结义 · 涿郡
2. 虎牢关 · 三英战吕布
3. 卧龙出山 · 博望坡
4. 长坂坡 · 单骑救主
5. 赤壁 · 东风卷烈焰
6. 定军山 · 汉室复兴

通过**大地图经营 + 战棋战斗**逐步占领城池、招揽武将、研究科技、发展内政，最终完成六回章回。

难度：

| 难度 | 说明 |
|---|---|
| 休闲 | 敌军较弱，粮草丰足，适合看剧情 |
| 普通 | 标准攻防，需要一定谋略 |
| 史诗 | 敌军精锐、诸侯环伺，适合挑战 |

## 3. 大地图

### 3.1 资源

| 资源 | 用途 |
|---|---|
| 金 | 征兵、建筑升级、买装备、外交赠礼、招贤 |
| 粮 | 军队消耗、赈济、部分事件 |
| 兵 | 城池驻军，出征时消耗 |
| 科技点 | 研究科技树 |
| 声望 | 招贤、部分事件与外交 |
| 军令 | 每回合可出征次数，默认 2 次 |

### 3.2 回合流程

1. 查看军情纪要、当前目标、城池状态。
2. 处理内政：征兵、赈济、巡查、修城、招贤。
3. 选择城池出征，或进行外交、科技、装备调整。
4. 点击「结束回合」。
5. 结算收入、处理随机事件、敌军行动。
6. 进入下一回合。

> 战斗中不能存档；每回合结束与战斗后会触发自动存档。

### 3.3 城池

点击城池打开城池面板：

- **概况**：兵力、城防、治安、民心、产出。
- **军政**：
  - 征兵 +500
  - 开仓赈济（提升民心）
  - 巡查治安
  - 修缮城防
  - 招贤馆
  - 出征
- **营造**：农田、市集、兵营、城墙、书院、铁匠铺。
- **太守**：委任武将，提升收入/治安。
- **武将**：查看驻守武将。

建筑效果：

| 建筑 | 效果 |
|---|---|
| 农田 | 粮草收入 |
| 市集 | 金钱收入 |
| 兵营 | 兵员上限、征兵效率 |
| 城墙 | 城防、守城减伤 |
| 书院 | 每回合科技点 |
| 铁匠铺 | 全军攻击 +1%/级，商肆折扣 |

### 3.4 出征

- 选择相邻敌方城池。
- 进入布阵：最多 5 名武将。
- 选择阵形与出战兵力。
- 胜利后占领城池，获得战利品；失败损失兵力。

## 4. 外交

顶部「外交」进入势力列表：

- **赠礼**：消耗金，提升关系。
- **结盟**：关系 ≥70，可缔结盟约，盟约期间对方不进攻。
- **停战 / 破盟**：根据关系与局势操作。
- 占领城池会降低该势力关系；灭亡势力后其城池归你。

关系过低时，敌方更可能进攻；盟约可以争取发展时间。

## 9. 战斗 · 核心规则

### 9.1 行动

每名单位按速度进入行动序。轮到你时：

- **移动**：蓝色格子，受移动力/地形/天气影响。
- **攻击**：红色范围，消耗行动。
- **战法**：消耗士气，按技能类型选择目标。
- **待机**：结束该武将行动。
- **撤回**：移动后、攻击前可回到原位（`Z`）。

攻击/战法/待机会结束该单位本回合行动。

### 9.2 命中与伤害

- 命中受速度、地形、天气、技能影响。
- 伤害受攻击、防御、兵种克制、地形、高低差、夹击、冲锋、暴击影响。
- 战前会显示：**预计伤害、命中率、暴击率、反击风险、夹击**。

### 9.3 反击与夹击

- 近战攻击可能触发目标反击。
- 目标相邻有攻击者友军时形成夹击，伤害提升。

### 9.4 兵种克制

- 枪兵 → 骑兵
- 骑兵 → 弓兵
- 弓兵 → 步兵
- 步兵/枪兵/骑兵/弓兵/军师/指挥各有定位

### 9.5 士气与战法

- 攻击、受击、部分战法会积累士气。
- 士气达到消耗即可释放战法。
- 34 个战法：单体/范围/全军/治疗/增益/控制/火攻/箭雨等。
- 战法可能附加灼烧、降防、眩晕、回血、加士气等。

### 9.6 地形

11 种地形：

平原、官道、密林、丘陵、山岩、江水、木桥、村落、城墙、河滩、焦土。

- 森林：防御/闪避，移动消耗高。
- 丘陵/山岩：高低差与防御。
- 江水：不可通行（除非桥）。
- 木桥：通道。
- 城墙/村落：防御加成。
- 焦土：火场相关。

### 9.7 天气

| 天气 | 影响 |
|---|---|
| 晴 | 无特殊 |
| 风 | 火攻 +30%，弓兵射程 +1 |
| 雨 | 火攻失效，弓兵命中降低，移动 -1 |
| 雾 | 远程射程 -1，命中降低 |
| 雪 | 移动 -1，骑兵速度降低 |

### 9.8 火场

火计/火船会留下燃烧区域，进入或停留会受到伤害；雨天会削弱火攻。

### 9.9 目标与增援

- **歼灭**：击败全部敌军。
- **Boss**：击败指定主将（可能第 3 回合登场）。
- **坚守**：坚持指定回合数。
- 部分关卡有增援波次、盟军、特殊事件。
- Boss 战有图生视频 cut-in。

### 9.10 自动战斗

- 右上角「自动」或 `A` 键。
- AI 接管我方全部行动：移动、普攻、战法、治疗。
- 自动开启时默认 ×2，可切 ×3。
- 再点一次关闭，当前 AI 行动结束后交还控制。
- 自动战斗使用同一套伤害/目标/寻路逻辑。

### 9.11 目标面板 / 威胁范围

- 顶部目标进度条：敌军剩余 / Boss 血量 / 坚守回合。
- 悬停敌军（手机点敌军）显示其移动 + 攻击威胁范围。
- 行动序可点击查看完整队列。

### 9.12 胜负

- 达成目标：胜利。
- 我方全灭或目标失败：战败。
- 故事战斗失败可重新布阵；攻城失败损失兵力。
- 战后结算：回合、斩将、存活、余力、本场 MVP、升级/装备。

## 12. 小技巧

1. 先查看伤害预测，避免高反击目标。
2. 枪兵顶骑兵，骑兵切弓兵，弓兵压步兵。
3. 森林/丘陵能显著提升生存。
4. 夹击与高低差是伤害核心。
5. 战法不要只看伤害，降防/眩晕/治疗同样关键。
6. 自动战斗适合刷资源，但高难 Boss 建议手动。
7. 移动后先别急着攻击，必要时按 `Z` 撤回。
8. 套装 2/4 件效果可以改变 build。
9. 雨天别依赖火攻；风天火攻更强。
10. 守城战注意城墙与城防。

## 14. FAQ

**Q：为什么有些单位看起来是 2D 立绘？**  
A：战场单位是 MiniMax H3 生成的全身立绘 + 透明抠图，属于 2.5D 方案，不是 3D 骨骼模型。

**Q：为什么视频只有桌面端？**  
A：手机端为保证清晰度/性能回退到静态图；可在设置开启「精简模式」进一步降低负载。

**Q：存档在哪里？**  
A：浏览器 `localStorage`。清浏览器数据会丢失；建议用存档导出备份。

**Q：可以商用吗？**  
A：不可以。项目与生成素材均为非商业用途，详见 `LICENSE` 与 `LICENSE-ASSETS`。

**Q：素材是 AI 生成的吗？**  
A：人物/单位/道具/建筑/地形/背景/视频由 MiniMax H3 生成；UI、程序化音频与代码由 DeepSeek Flash 辅助生成。详见 [ASSETS.md](ASSETS.md)。
